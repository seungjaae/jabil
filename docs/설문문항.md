# 수요 조사 설문 문항 (구글 폼용)

사업계획서 12번 로드맵의 **1개월차 목표**를 이 설문 하나로 해결하는 것이 목적입니다.

- 자취생 20명 인터뷰
- "돈 내겠다"는 사람 5명 확보
- 서비스 메뉴 10개 확정

## 만드는 법

1. [docs.google.com/forms](https://docs.google.com/forms) → **빈 양식**
2. 아래 문항을 그대로 옮깁니다 (8문항, 응답 시간 30초 목표)
3. 우측 상단 **[보내기] → 🔗 링크 탭 → 복사**
4. 복사한 주소를 `data/site-data.js` 의 `survey.url` 에 붙여넣습니다
5. 응답 탭 → 우측 상단 초록 시트 아이콘 → 구글 시트로 자동 연결 (CSV 내려받기 가능)

> ⚠️ **"로그인 필요" 설정은 반드시 꺼두세요.** 켜져 있으면 응답률이 절반 이하로 떨어집니다.
> 설정 → 응답 → "이메일 주소 수집" 끄기, "응답 횟수 1회로 제한" 끄기

## 문항

### 1. 지금 사는 곳은 어디인가요?
`객관식` — *지역 확정(사업계획서 5-4)에 쓸 데이터입니다*

- 경기대 정문 (이의동)
- 경기대 후문
- 연무동
- 그 외 수원
- 그 외 지역

### 2. 자취 형태를 골라주세요
`객관식`

- 원룸 (혼자)
- 원룸 (둘 이상)
- 오피스텔
- 기숙사
- 본가

### 3. ⭐ 고장났거나 불편한데 **그냥 두고 계신 것**이 있나요?
`체크박스 (복수 선택)` — *이 문항이 메뉴 10개를 확정합니다*

- 전구·형광등이 나갔거나 깜빡임
- 액자·선반·후크를 걸고 싶은데 못 박기가 어려움
- 문이 처졌거나 잘 안 닫힘
- 조립해야 할 가구가 박스째 있음
- 컴퓨터·모니터·프린터·공유기 설치
- 욕실 곰팡이 / 실리콘이 지저분함
- 배수구가 막혔거나 물이 잘 안 내려감
- 창문 웃풍이 심함
- 커튼봉·블라인드를 달고 싶음
- 방충망이 찢어짐
- 냉장고·세탁기를 옮기고 싶음
- 없음
- 기타: ___

### 4. 그걸 **얼마나 오래** 그대로 두셨나요?
`객관식` — *"5분짜리 일을 부탁할 곳이 없다"는 가설의 직접 검증*

- 1주일 미만
- 1개월 정도
- 3개월 이상
- 6개월 이상 / 이사 올 때부터

### 5. 왜 아직 안 고치셨나요?
`체크박스 (복수 선택)`

- 방법을 몰라서
- 공구가 없어서
- 사람을 부르기엔 일이 너무 작아서
- 출장비가 아까워서
- 낯선 사람을 집에 들이기가 부담돼서
- 집주인에게 말하기 애매해서
- 귀찮아서 / 계속 미루게 돼서

### 6. ⭐ **전구 하나 갈아주는 데** 얼마면 부르시겠어요?
`객관식` — *가격 상한을 잡는 문항. 사업계획서 6-3의 원가 계산과 대조합니다*

- 5,000원
- 10,000원
- 15,000원
- 20,000원
- 30,000원 이상
- 얼마여도 안 부를 것 같다

### 7. 어떤 점이 있으면 **안심하고** 부르시겠어요?
`체크박스 (복수 선택)` — *사업계획서 11-8의 "고객은 자격증을 안 물어본다" 가설 검증*

- 2인 1조로 방문
- 작업 전후 사진을 남겨줌
- 파손 시 보험 처리
- 가격을 미리 알려줌
- 같은 학교 학생이 함
- 후기가 실명으로 올라와 있음
- 여성 작업자가 옴

### 8. 서비스가 시작되면 알려드릴까요?
`단답형` — *이게 그대로 대기자 명단이 됩니다*

> 카카오톡 ID 또는 전화번호를 남겨주시면 오픈 때 **첫 이용 할인**을 드립니다. (선택)

## 배포처

| 곳 | 방법 |
|---|---|
| 에브리타임 | 자유게시판 · 새내기게시판에 링크 + 3번 문항 스크린샷 |
| 과 단톡방 | 짧게: "자취 불편한 거 조사 중인데 30초만" |
| 오픈채팅 | 경기대 자취방 / 원룸 관련 오픈채팅방 |
| 대면 | 지인 방 점검(계획서 14-4) 갈 때 옆에서 바로 응답받기 — 응답률 100% |

## 목표

- **응답 20건** → 인터뷰 목표 달성
- **6번에서 15,000원 이상 5명** → "돈 내겠다는 사람 5명" 달성
- **3번 상위 10개** → 서비스 메뉴 확정
